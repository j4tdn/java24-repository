 Vd: Iterable<T>
 
 + T: generic Type có thể đặt bất kỳ ký tự nào, thường là ký tự đơn
 viết hoa
 + Generic<T>: generic interface là interface có tham số truyền vào là
 generic type
 	Kiểu Iterable có tham số truyền vào là generic type KDL T, T là đại
 diện cho kiểu dữu liệu đối tượng
 	Là có thể truyền vào KDL đối tượng nào đó cho T khi gọi Iterable


 => Iterable<Integer>
 => Iterable<String>
 
 
 + Giúp tạo ra các common utils methods có thể áp dụng cho bất kỳ KDL
 đối tượng nào
 + Lợi ích: hạn chế raw(objects) types, bắt buộc phải khai báo KDL cụ
 thể thay vì dùng object cho mọi phần ưtr
 	--> hỗ trợ bắt lỗi tại compile
 	
 Ôn tập
 --------------
 Iterable<T>    :
 Collection<T>	:
 List<T>		:             		--> ArrayList, LinkedList
 Set<T>			:					--> HashSet, LinkedHashSet, TreeSet
 Map<K,V>		: Set<Entry<K,V>> 	--> HashMap, LinkedHashMap, TreeMap
 
 
 Set<E> ==> set.add(e)
 		==> map.put(new Entry<>(e, PRESENT))
 		
 Từ khóa 'var'		
 --------------
 - Hỗ trợ thay thế cho khai báo KDL phía bên trái của biến
 	+ Dựa vào bên phải để biết KDL lúc compile
 	
 - Thông thường để biết biến có KDL là gì
 	+ Bên trái là KDL lúc compile
 	+ Bên phải là KDL lúc runtime
 
 - Lưu ý: 
 	+ var không thể chứa giá trị null
 	+ var không thể là tham số truyền vào của hàm
 	+ var không thể chứa giá trị là một lambda
